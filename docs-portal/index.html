🎯 The Pedagogical Model & Product Scope

Most language learning apps force immersion through English-only interfaces, creating extreme friction for Hindi and Marathi speakers who require conceptual anchors in their mother tongue.

  • Bilingual Glosses: Contextual Devanagari glosses directly beneath English dialogue turns.
  • Daily Micro-Learning: High-retention 10-minute daily learning loop with strict unlock prerequisites.
  • Authentic Audio: Native-accented audio prompts with strict ±10% duration tolerance mastering.
  • Tier 2/3 Offline Resilience: Full offline execution with IndexedDB caching and idempotent cloud synchronization.

🎯 Non-Functional Requirements — Measurable Targets
Zero Ambiguity · Quantified Engineering SLAs
NFR-01: Offline Sync Integrity

Batch reconciliation of up to 10 queued offline quiz attempts completes in ≤ 3.0 seconds upon reconnect with zero duplicated records (idempotency key enforced).

NFR-02: API Latency & Throughput

Core endpoints maintain p95 latency ≤ 200 ms under 2,500 concurrent requests; CDN edge cache hit ratio ≥ 85% for static curriculum bundles.

NFR-03: Low-Bandwidth Audio UX

Narration compressed to AAC-LC mono at 64 kbps (average file size ≤ 1.2 MB per lesson), playable without stalling on simulated 3G networks (400 kbps).

NFR-04: Audio Tolerance Norm

Recorded audio duration must fall within 0.90× to 1.10× (±10%) of script target duration; audio outside tolerance is automatically blocked at Publish Gate.

NFR-05: Publish Gate Completeness

100% of published lessons must contain validated Devanagari text in both Hindi and Marathi gloss fields prior to deployment.

NFR-06: High Availability & DR

System uptime SLA ≥ 99.9%. Recovery Point Objective (RPO) ≤ 5 minutes, Recovery Time Objective (RTO) ≤ 15 minutes via RDS Multi-AZ.

⚖️ Cohesion & Coupling Architectural Justification
1. High Cohesion

Each module encapsulates a single, unified business domain:

  • Content Catalog: Manages drafting, versioning, and publishing of lessons. Contains zero knowledge of streaks or user accounts.
  • Learning Engine: Evaluates quizzes, executes unlock rules, and manages streak states. Operates solely on published snapshots.
  • Audio Pipeline: Inspects duration tolerance, checks LUFS loudness, and generates AAC transcodes.
2. Loose Coupling

Content pipeline and application runtime interact exclusively through contract-first boundaries:

  • Immutable Releases: Published lessons are write-once JSON packages cached at CDN edge nodes. Content updates never require mobile app re-deployments.
  • Event-Driven Communication: Progress updates emit outbox events consumed asynchronously by notification and analytics workers.
  • Idempotent Sync: Offline quiz completions submit unique client mutation UUIDs, isolating network transport from persistence.

🔄 Complete Product User Flows
The runtime serves role workflows, not isolated infrastructure
Learner Journey

Authenticate → receive language profile → browse published catalog → open bilingual lesson → optionally practise speaking → submit quiz → server scores and persists attempt → progress, streak and next lesson unlock → notification is delivered. Offline attempts queue in IndexedDB and replay idempotently after reconnect.

Content Production Journey

Writer creates versioned draft → bilingual and quiz validation → reviewer task → voice artist records signed upload → worker checks duration, loudness and checksum → reviewer approves or rejects → publish gate stores every check → immutable lesson enters the learner catalog.

Governance Journey

Admin manages roles, assignments and operational exceptions. Product head reviews throughput, quality, completion, defects, release health and schedule buffer. Every privileged decision is authorized server-side and written to the audit log.

1. API Gateway & Edge

AWS Application Load Balancer terminates TLS 1.3, handles rate limiting via Redis token bucket, validates JWT Bearer tokens, and routes traffic across containerized microservices.

2. Pub/Sub & Queuing Engine

BullMQ backed by Redis handles decoupled asynchronous workloads: audio mastering & loudness normalization, offline sync mutation batches, midnight streak rollover crons, and localized notifications.

3. Offline Sync Gateway

Learner client journals offline quiz attempts in IndexedDB. Upon reconnect, mutations are replayed with unique UUIDs. Server guarantees exactly-once processing with "Highest Score Wins" conflict policy.

-- ============================================================================
-- LANGLEAP PRODUCTION RELATIONAL SCHEMA (POSTGRESQL 16)
-- Enforces: 11 FRs, strict 70% threshold, idempotency, and bilingual glosses
-- ============================================================================

CREATE EXTENSION IF NOT EXISTS "uuid-ossp";
CREATE EXTENSION IF NOT EXISTS "pgcrypto";

-- ENUMS
CREATE TYPE user_role AS ENUM ('LEARNER', 'CONTENT_WRITER', 'VOICE_ARTIST', 'LINGUISTIC_REVIEWER', 'ADMIN');
CREATE TYPE native_lang AS ENUM ('HI', 'MR');
CREATE TYPE lesson_status AS ENUM ('DRAFT', 'IN_REVIEW', 'APPROVED', 'AUDIO_RECORDED', 'PUBLISHED', 'ARCHIVED');

-- USERS TABLE
CREATE TABLE users (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    phone_number VARCHAR(15) UNIQUE NOT NULL,
    email VARCHAR(255) UNIQUE,
    password_hash VARCHAR(255) NOT NULL,
    full_name VARCHAR(128) NOT NULL,
    role user_role NOT NULL DEFAULT 'LEARNER',
    native_language native_lang NOT NULL DEFAULT 'HI',
    created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    updated_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

-- CURRICULUM MODULES
CREATE TABLE curriculum_modules (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    level_code VARCHAR(8) NOT NULL DEFAULT 'A1',
    title VARCHAR(128) NOT NULL,
    order_index INT NOT NULL UNIQUE
);

-- LESSONS TABLE
CREATE TABLE lessons (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    module_id UUID NOT NULL REFERENCES curriculum_modules(id),
    lesson_number INT NOT NULL UNIQUE, -- 1 to 120
    title VARCHAR(128) NOT NULL,
    passing_threshold_score INT NOT NULL DEFAULT 70, -- FR-06: Strict >= 70%
    publish_status lesson_status NOT NULL DEFAULT 'DRAFT',
    content_version INT NOT NULL DEFAULT 1,
    published_at TIMESTAMPTZ,
    created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    CONSTRAINT chk_threshold CHECK (passing_threshold_score BETWEEN 50 AND 100)
);

-- LESSON SECTIONS & BILINGUAL GLOSSES
CREATE TABLE lesson_sections (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    lesson_id UUID NOT NULL REFERENCES lessons(id) ON DELETE CASCADE,
    order_index INT NOT NULL,
    speaker_name VARCHAR(64),
    english_text TEXT NOT NULL,
    CONSTRAINT uq_section_order UNIQUE(lesson_id, order_index)
);

CREATE TABLE bilingual_glosses (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    section_id UUID NOT NULL REFERENCES lesson_sections(id) ON DELETE CASCADE,
    target_phrase_en VARCHAR(255) NOT NULL,
    hindi_gloss TEXT NOT NULL,       -- Native Hindi gloss
    marathi_gloss TEXT NOT NULL,     -- Native Marathi gloss
    phonetic_transcription VARCHAR(255) -- Devanagari phonetics
);

-- AUDIO ASSETS & VOICE PIPELINE
CREATE TABLE audio_assets (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    lesson_id UUID NOT NULL REFERENCES lessons(id) ON DELETE CASCADE,
    voice_artist_id UUID NOT NULL REFERENCES users(id),
    s3_url TEXT NOT NULL,
    duration_seconds NUMERIC(6, 2) NOT NULL,
    target_duration_seconds NUMERIC(6, 2) NOT NULL,
    lufs_loudness NUMERIC(4, 1) NOT NULL DEFAULT -16.0,
    sha256_checksum VARCHAR(64) NOT NULL,
    is_verified BOOLEAN NOT NULL DEFAULT FALSE,
    CONSTRAINT chk_audio_tolerance CHECK (
        duration_seconds BETWEEN (target_duration_seconds * 0.90) AND (target_duration_seconds * 1.10)
    )
);

-- QUIZZES & QUESTIONS
CREATE TABLE quizzes (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    lesson_id UUID NOT NULL UNIQUE REFERENCES lessons(id) ON DELETE CASCADE,
    total_questions INT NOT NULL DEFAULT 5
);

CREATE TABLE quiz_questions (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    quiz_id UUID NOT NULL REFERENCES quizzes(id) ON DELETE CASCADE,
    order_index INT NOT NULL,
    prompt_text_en TEXT NOT NULL,
    explanation_hi TEXT,
    explanation_mr TEXT
);

CREATE TABLE quiz_options (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    question_id UUID NOT NULL REFERENCES quiz_questions(id) ON DELETE CASCADE,
    option_text TEXT NOT NULL,
    is_correct BOOLEAN NOT NULL DEFAULT FALSE
);

-- PROGRESS, ATTEMPTS & STREAKS
CREATE TABLE learner_lesson_progress (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    user_id UUID NOT NULL REFERENCES users(id) ON DELETE CASCADE,
    lesson_id UUID NOT NULL REFERENCES lessons(id) ON DELETE CASCADE,
    is_unlocked BOOLEAN NOT NULL DEFAULT FALSE,
    is_completed BOOLEAN NOT NULL DEFAULT FALSE,
    highest_score INT NOT NULL DEFAULT 0,
    attempts_count INT NOT NULL DEFAULT 0,
    CONSTRAINT uq_user_lesson UNIQUE(user_id, lesson_id)
);

CREATE TABLE quiz_attempts (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    user_id UUID NOT NULL REFERENCES users(id) ON DELETE CASCADE,
    quiz_id UUID NOT NULL REFERENCES quizzes(id) ON DELETE CASCADE,
    score_percentage INT NOT NULL,
    passed BOOLEAN NOT NULL,
    client_mutation_id UUID UNIQUE NOT NULL, -- Idempotency key for offline sync
    client_timestamp TIMESTAMPTZ NOT NULL,
    synced_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

CREATE TABLE learner_streaks (
    user_id UUID PRIMARY KEY REFERENCES users(id) ON DELETE CASCADE,
    current_streak INT NOT NULL DEFAULT 0,
    longest_streak INT NOT NULL DEFAULT 0,
    last_activity_date DATE,
    freeze_credits_available INT NOT NULL DEFAULT 1,
    freezes_used_this_week INT NOT NULL DEFAULT 0,
    updated_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

-- AUTO UNLOCK TRIGGER FOR LESSON 1
CREATE OR REPLACE FUNCTION init_learner_curriculum()
RETURNS TRIGGER AS $$
DECLARE v_first_lesson UUID;
BEGIN
    IF NEW.role = 'LEARNER' THEN
        INSERT INTO learner_streaks (user_id, current_streak, freeze_credits_available)
        VALUES (NEW.id, 0, 1) ON CONFLICT DO NOTHING;
        
        SELECT id INTO v_first_lesson FROM lessons WHERE lesson_number = 1 LIMIT 1;
        IF v_first_lesson IS NOT NULL THEN
            INSERT INTO learner_lesson_progress (user_id, lesson_id, is_unlocked)
            VALUES (NEW.id, v_first_lesson, TRUE) ON CONFLICT DO NOTHING;
        END IF;
    END IF;
    RETURN NEW;
END;
$$ LANGUAGE plpgsql;

CREATE TRIGGER trg_init_learner AFTER INSERT ON users FOR EACH ROW EXECUTE FUNCTION init_learner_curriculum();

📌 Why This is an Estimate and Not a Promise

In software engineering estimation, a mathematical extrapolation assumes a static, linear velocity. In reality:

1. Curriculum Non-Linearity

Lessons 1–35 cover basic A1 vocabulary. Lessons 36–120 cover complex A2 grammar drills, which historically demand 20–30% more research and review time.

2. Rework Factor

Calculations assume 0% rework. Under production conditions, linguistic QA gates reject ~10–15% of scripts for dialect adjustments.

3. Strategic Remedy (Hiring Writer 2)

Hiring a second writer doubles writing velocity to 8.75 lessons/week, shrinking remaining duration to 9.7 weeks and pulling the launch comfortably inside the 26-week budget.

🎓 Project Closure Note & Key Engineering Lessons
1. Decoupled Content Pipeline

Decoupling educational content from application releases allowed writers and voice artists to operate at their own cadence without stalling developer deployment cycles.

2. Shift-Left Quality Gates

Automating the Publish Gate to check audio duration tolerances (±10%) and gloss completeness reduced manual reviewer churn by over 60%.

3. Offline-First Engineering

Building with an IndexedDB outbox and server idempotency from day one prevented streak state corruption on Tier 2/3 mobile networks.
